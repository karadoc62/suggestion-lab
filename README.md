# Suggestion Lab

Application pédagogique développée afin de découvrir une architecture
Angular / Java EE.

## Technologies prévues

- Angular
- Java
- Gradle
- WildFly
- PostgreSQL
- MongoDB
- Cypress
- AsciiDoc

## Architecture

Le dépôt est séparé en trois parties :

- `client` : application Angular
- `server` : application Java
- `documentation` : documentation technique
